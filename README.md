## What You Get

- Each mental break has a configurable chance from 0% to 100% for a pawn to avoid the mental break by giving themselves a hair cut.
  - Minor breaks default to 30%, Major breaks default to 15%, Extreme breaks default to 5%
  - Setting a mental break to 100% means it will always be replaced by a hair cut. Useful for disabling mental breaks you hate.
  - Supports all mental breaks added by mods.
- For each hair style you can say which intentity of mental break can choose that hair cut.
  - Sensible defaults for all DLC hair.
  - Supports all hair styles added by mods.
